Where do I find my admin token?

On the server running the toolkit, open a terminal and run:

sudo sed -n 's/^TOOLKIT_ADMIN_SECRET=//p' /srv/hospitable-ai/account-one/secrets/credentials.env

Copy the value shown into the token box, then click Connect. If your instance has a different name or location, replace /srv/hospitable-ai/account-one with your instance directory (the INSTANCE_DIR value in instance.env).

This is your toolkit admin token, separate from your Hospitable API key. Keep it private. If you do not have server access, ask the person who installed the toolkit.
