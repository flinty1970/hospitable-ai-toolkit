Where do I find my admin token?

Linux: run this on the computer hosting the toolkit. The command uses sudo for installations that require administrator access to Docker.

sudo docker exec account-one-toolkit-1 python -c "from pathlib import Path; from hosting.container_runtime import read_credentials; print(read_credentials(Path('/run/toolkit-secrets/credentials.env'))['TOOLKIT_ADMIN_SECRET'])"

Windows PowerShell / macOS Terminal: use the same command without sudo:

docker exec account-one-toolkit-1 python -c "from pathlib import Path; from hosting.container_runtime import read_credentials; print(read_credentials(Path('/run/toolkit-secrets/credentials.env'))['TOOLKIT_ADMIN_SECRET'])"

This toolkit has been tested on Linux only. Windows / Docker Desktop remains untested.

Replace account-one-toolkit-1 with your container name. To find it, run sudo docker ps --format "{{.Names}}" on Linux, or docker ps --format "{{.Names}}" on Windows/macOS. If your Linux Docker access already works without sudo, you can omit it.

Alternatively, open your instance's secrets/credentials.env file on the host and copy only the value after TOOLKIT_ADMIN_SECRET=. Linux example: /srv/hospitable-ai/account-one/secrets/credentials.env. A Windows installation uses the folder you chose, for example C:\hospitable-ai\account-one\secrets\credentials.env.

Paste the value into the token box and click Connect. This is your toolkit admin token, separate from your Hospitable API key. Keep it private. If you do not have host/Docker access, ask the person who installed the toolkit.

AI service and model

Choose the service this toolkit uses to prepare drafts for every imported property. This does not change Hospitable’s AI settings.

Use an API key from your provider account. ChatGPT, Claude and other chat subscriptions do not supply API access. Keys are stored privately on this server and never displayed again. Use HTTPS or a trusted SSH tunnel when entering keys remotely.

OpenAI keys · Anthropic keys · xAI keys · Gemini keys

Clear the Model box to see the full loaded list; typing filters the suggestions. Click Load available models to refresh the list from your provider. Some listed models may not support text drafts; test your choice before saving. A test makes a small billable API request without guest or property data.

Saving applies to the next draft without a restart. Previous drafts remain unchanged. Failed calls go to human review.

Owner email alerts

These alerts are sent by this toolkit, separately from Hospitable notifications. Owner email is required for human-response alerts. Configure your email provider's SMTP connection. Use an app password if your provider requires one.

Gmail: use your full Gmail address for username and sender, port 587 with STARTTLS, and a Google app password. Owner recipients can be separated by commas.
