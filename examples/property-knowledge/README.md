# Generic property knowledge starter pack

These are editable templates, not verified facts about a real property. They use common short-term-rental topics without real names, addresses, passwords, codes, contractor details or automation configuration.

Replace every `[PLACEHOLDER]` with a verified fact or remove the unsupported section. Remove template/editor instructions before indexing. Do not bulk-copy this folder into a property's knowledge index: this README and the AI prompt are authoring instructions, not guest knowledge.

Suggested guest files:

- `property_facts.md`: occupancy, layout, parking, access limitations and outdoor space.
- `address_parking.md`: guest-approved address, map/directions, spaces, limits, permits, street restrictions and EV policy.
- `arrival_departure.md`: arrival, checkout and requests requiring confirmation.
- `wifi.md`: guest network name, credential location, coverage and workspace.
- `house_rules.md`: occupancy, visitors, pets, noise, smoking and EV policy.
- `bins_recycling.md`: bin labels/colours, accepted waste, collection and responsibility.
- `guest_supplies.md`: essentials, spare locations and replenishment policy.
- `appliances.md`: model-specific guest operation, without repair instructions.
- `heating_hot_water.md`: ordinary guest controls and fault reporting.
- `housekeeping.md`: guest cleaning supplies, linen and routine service information.
- `local_area.md`: verified nearby essentials, transport and urgent-help contacts.

Use `AI_PROMPT.md` with any text-capable AI assistant. Supply only redacted, approved material. An AI draft is not factual verification: compare it with your current house guide, installed equipment and local waste-provider instructions before use.

After review, place only completed guest-safe `.md` files into the selected property's `docs/` folder. For existing Markdown files, use Property knowledge -> View / replace. To add a new file, copy it to the host's property `docs/` folder or use the supported file workflow; the browser upload currently accepts PDFs, not arbitrary new Markdown uploads. Then update property knowledge and test representative guest questions while response mode remains Paused.
